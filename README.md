# Proyecto con Docker

Este proyecto está configurado para ser ejecutado mediante Docker utilizando Docker Compose.

## Instrucciones

1. **Clona el repositorio** en tu máquina local:

   ```bash
   git clone https://github.com/jmmorales11/Taller_Clse.git

2. **Ejecuta el siguiente comando para construir y levantar los contenedores**:

    ```bash
    docker-compose up --build
Este comando realiza dos acciones:construye las imágenes de los contenedores y levanta los contenedores de acuerdo a la configuración de docker-compose.yml
